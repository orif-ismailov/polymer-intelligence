<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Admin wizard → POST /sources, /sources/{id}/test | Admin-supplied URLs + config cross to the fetch path |
| Adapter test() → external URL | Backend makes an outbound HTTP request to an admin-supplied URL |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-19 | Tampering (SSRF) | html_table/rss adapter test() fetch | mitigate | `is_safe_url()` (DEC-ssrf-dns-resolution) called before any HTTP fetch; unsafe url -> TestResult ok=false (asserted in adapter tests) |
| T-04-20 | Tampering (enable bypass) | PATCH /sources/{id} | mitigate | Server-side invariant: is_enabled=true requires last_test_ok_at IS NOT NULL -> 422 (test_enable_gate); UI gate is UX-only |
| T-04-21 | Elevation | POST/PATCH /sources | mitigate | require_admin on all source writes; non-admin -> 403 |
| T-04-22 | Info Disclosure | GET /sources | mitigate | Health list SELECT excludes the `config` column and any secrets (source name/adapter/health only) |
| T-04-23 | Tampering (code exec) | telegram_channel/llm_page pending | mitigate | Pending stubs run no engine; test() returns ok=false; no LLM/MTProto code path executes in Phase 4 |
| T-04-SC | Tampering | pip install feedparser | mitigate | feedparser is a long-established PyPI package; if added, verify on pypi.org/project/feedparser before install; fallback is stdlib xml.etree.ElementTree (no install) — prefer fallback to avoid a new dependency |
</threat_model>
