## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge padding, chip inner gap |
| sm | 8px | Compact element spacing, table cell padding (vertical) |
| md | 16px | Default element spacing, form field gap, card padding |
| lg | 24px | Section padding, sidebar group gap |
| xl | 32px | Layout gaps, panel header padding |
| 2xl | 48px | Major section breaks, page content top padding |
| 3xl | 64px | Page-level spacing (reserved; sidebar width = 240px outside scale) |

Exceptions:
- Sidebar width: 240px (fixed, matches mockup proportions — outside 8-pt scale by design)
- Touch targets (interactive icon buttons): minimum 44px × 44px
- KPI card sparkline height: 40px (fixed compact size per mockup §3.2)
- Right detail panel width: 400px fixed (mockup §3.2 layout contract)
- Table row height: 52px (accommodates two lines of content at sm vertical padding)

## Typography

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px | 400 (regular) | 1.5 | Table cells, sidebar items, form labels, card body |
| Label | 12px | 600 (semibold) | 1.4 | Status chips, column headers, filter tags, captions, "Updated N min ago" |
| Heading | 20px | 600 (semibold) | 1.2 | Page headers, panel section titles, modal titles |
| Display | 28px | 600 (semibold) | 1.1 | KPI numeric values (e.g. "248", "$1,082") — size alone creates the KPI hierarchy |

Font family: `Inter, system-ui, sans-serif` for all roles above.
Font family `mono`: `JetBrains Mono, Menlo, monospace` — reserved for request IDs (REQ-YYYY-MM-DD-NNNNN), prices in table cells where alignment precision matters, and hash/code values.

Maximum weights in use: 400 (regular) and 600 (semibold). Executor must use only these two values — no 500, no 700.

## Screens and Interaction Contracts

### Global Shell (Wave 1)

**Left sidebar (240px fixed, `bg-background-secondary`):**
- Logo + "Polymer Intelligence" wordmark at top (20px semibold, accent text) — maps to Heading scale size for prominent brand presence
- Nav groups with 12px uppercase label: MAIN / REQUESTS / SOURCES / SETTINGS
- Active item: left border 2px accent, text-foreground, bg-background-tertiary
- Collapsed hover state: bg-background-tertiary transition-colors 150ms
- Footer: current user avatar initials (24px circle), display name, role badge
- Role-based item visibility: viewer sees no SETTINGS > Alerts rule builder write actions

**App layout:** fixed sidebar + scrollable main content area. Header per page (not global).

**Auth guard:** all routes except `/login` require valid JWT; expired token → redirect to `/login`.

### Dashboard Home (`/`)

**Primary visual anchor:** the KPI cards row — 28px Display values draw the eye first, establishing at-a-glance health of the market before the user scans lower panels.

**KPI cards (5):** Total Buyers, Total Sellers, Active Requests, Hot Leads, Price Alerts.

- AI-dependent KPI ("Hot Leads"): renders in final layout shape; numeric shows real count from `requests WHERE lead_score IS NOT NULL` (empty = 0 in Phase 4 since Phase 5 fills lead_score). Chip label: "high priority". Icon: flame (lucide `Flame`).
- Non-AI KPIs: live from DB aggregates.
- Card anatomy: icon (24px, `foreground-muted`) + label (12px weight 600, `foreground-muted`) + value (28px weight 600, `foreground`) + delta chip (12px weight 600, `status-new` blue for neutral, accent green for positive).

**Live Market Feed panel:**
- Rows: BUYER chip / SELLER chip / REQUEST chip (kind colors) + product + volume + region + price + relative time + "View detail" link.
- "View all" link → `/requests` or `/signals`.
- Empty state: icon `Activity` (lucide, 32px, `foreground-muted`) + "No market activity yet" heading (14px weight 600, `foreground`) + "Signals will appear here as sources report" body (14px weight 400, `foreground-muted`).

**Price Trends panel:**
- Recharts `LineChart`, responsive container 100% width × 200px height.
- X-axis: date labels, 12px, `foreground-muted`. Y-axis: USD/MT, 12px, `foreground-muted`.
- Grid: `border-subtle` stroke, 1px.
- Legend: 12px labels, colored dots.
- "View all" → `/prices`.

**AI Market Signals panel (D-01):**
- Renders in final layout shape with placeholder rows.
- Each row: icon (24px) + insight text (14px, `foreground`) + time (12px, `foreground-muted`).
- Placeholder state: 3 rows showing icon + "AI analysis available after Phase 5" (14px, `foreground-subtle`) — NOT a blank card. No spinner.

**Top Buyer Requests / Top Seller Offers panels:**
- Ranked list, max 5 rows. Urgency chip (12px, urgency token). Volume + price (14px mono).

### Purchase Requests (`/requests`) — flagship screen

**Header row:**
- Left: "Purchase Requests" (20px semibold) + subtitle (14px, `foreground-muted`): "Real-time buyer requests collected from exchanges, websites and channels"
- Right: Search input (280px, lucide `Search` icon), Export button (outline), Settings icon button (`aria-label="Table settings"`, 44px touch target), "● Live Data" indicator (8px pulsing dot, accent + "Live Data" 12px accent text)

**Filter bar (below header):**
- Period select, Product select, Region select (not in mockup but standard), Source select, "More Filters" button (outline, `ChevronDown` icon).
- Active filters shown as removable chips below bar (12px, `bg-background-tertiary`, × remove).
- Reset: "Clear filters" text button (14px, accent).

**KPI cards (6):**
- Total Requests (248 + sparkline), Total Volume (MT + sparkline), Avg Target Price (USD/MT + sparkline), Hot Requests, Sources (count active), Updated (relative time "2 min ago").
- Sparkline: 40px height, `accent` stroke, no fill, 60-point window.
- "Hot Requests" AI-adjacent KPI: shows real count from `requests WHERE urgency='high'` — this is not AI-dependent, urgency comes from the wizard.

**Requests table (TanStack Table):**
- 10 rows per page. Pagination controls: "← Prev / Next →" + "Page N of M" + "248 results".
- Columns (fixed widths): Time (80px), Product (120px), Grade/Type (100px), Volume (80px mono), Target Price (100px mono), Region/Delivery (120px), Source (140px), Urgency (80px), Status (100px).
- Sortable columns: Time, Volume, Target Price (sort icon `ArrowUpDown`, 14px, `foreground-muted`).
- Row click: opens right detail panel (400px, slides in from right, not a modal).
- Selected row: `bg-background-tertiary` highlight.
- Status chips: 12px, rounded-full, 6px horizontal padding, color per status token.
- Urgency chips: 12px, color per urgency token, with icon — High: `Flame`, Medium: `Users`, Low: `Download`.
- Source cell: source name (14px) + kind badge (12px, `bg-background-tertiary text-foreground-muted`).
- Empty state (no requests or filter returns zero): icon `Inbox` (32px, `foreground-muted`) + "No requests found" heading + "Try adjusting your filters or check back later." body.

**Right detail panel (400px fixed, `bg-background-secondary`, border-l `border-DEFAULT`):**
- Header: status badge (top-left), request ID (14px mono, `foreground-muted`), product title (20px semibold), grade chip + urgency chip, close button `X` (top-right, 44px tap target).
- Section "Request Details": Volume, Target Price, Delivery Terms, Destination, Required Date, Payment Terms, Additional Info — all 14px. Labels 12px `foreground-muted`.
- Section "Source Information": Source name + kind, Posted Time, Detected Time — 14px, times in Asia/Tashkent format.
- Section "AI Analysis" (D-01 placeholder contract):
  - Match Score: progress bar (accent fill, `bg-background-tertiary` track, 8px height) + percentage text. Placeholder: bar empty (0%), text "—".
  - Price Analysis: always live in Phase 4 (D-02) — shows "N% above/below market average" from `price_points`. Display: 14px, positive delta = accent, negative = `urgency-medium`.
  - Demand Level: text value + icon. Placeholder: "Pending (Phase 5)".
  - Recommendation: text block. Placeholder: "AI analysis available after Phase 5" (14px, `foreground-subtle` italic).
- Section "Actions":
  - "Contact Buyer" — primary button (full-width, `bg-accent hover:bg-accent-dark`, white text, `ExternalLink` icon 16px). Opens `tg://` deep link + logs to `audit_log`. D-11 contract.
  - "Add Note" — outline button (full-width). Opens inline textarea (4 rows) + "Save Note" confirm. Note is team-only (not client-visible).
  - Status dropdown — `Select` component (shadcn), values: viewed / in_progress / offer_sent / matched / closed / cancelled. Current status pre-selected. On change: confirmation if transitioning to `cancelled` (see Copywriting).
  - "Assign Owner" — `Select` populated from `GET /admin/users` (staff list). Shows "Unassigned" placeholder.
  - "Mark as Processed" — secondary full-width button → sets status to `closed`.
  - All actions → `audit_log` (D-10). Server enforces valid transitions.
- Files list: collapsible section, icon `Paperclip` (16px) + "N files". Each row: file type icon + filename (14px) + size (12px, `foreground-muted`) + download link.

**Export button behavior (Claude's Discretion — resolved):**
- Format: CSV. Scope: current filtered result set, all columns (no pagination — backend streams).
- Label: "Export CSV". No secondary format offered in Phase 4.

### Sources (`/sources`)

**Sources list:**
- Cards or table rows per source. Columns: Name, Type badge (`html_table`/`rss`/`telegram_channel`/`llm_page`/`uzex_*`/`cbu_rates`), Status (enabled/disabled chip), Last Fetch (relative time, Asia/Tashkent), Consecutive Failures (count, `urgency-high` red if > 0), Enable/Disable toggle, Test button.
- `no_code=False` built-in adapters (`uzex_*`, `cbu_rates`): Test button visible, Enable/Disable toggle visible. No "Edit" in wizard.
- `telegram_channel` / `llm_page` with `last_test_ok_at IS NULL`: Status chip = "Pending activation (Phase 5)" badge (`bg-amber-500/20 text-amber-400 border border-amber-500/30`), Test button disabled with tooltip "Available after Phase 5", Enable toggle disabled. (D-05)
- `html_table` / `rss` (wizard-added): full Test + Enable flow live.

**"+ Add Source" wizard (D-04, D-05, D-06):**
- Entry: "Add Source" button (accent, `Plus` icon) top-right of sources page.
- Step 1 — Pick type: radio card group (4 cards in 2×2 grid): "HTML Table", "RSS Feed", "Telegram Channel" (with Phase 5 badge), "LLM Page" (with Phase 5 badge). Cards: 160px × 100px, icon (32px) + type name (14px weight 400, `foreground`) + description (12px weight 600, `foreground-muted`). Phase-5 types show amber "Phase 5" badge, are selectable (pre-staging allowed, D-05) but warn on selection.
- Step 2 — Configure: auto-form rendered from `GET /admin/source-types/{type}/config_schema`. Field types: text input, url input, select, textarea, integer. All fields carry labels (14px, `foreground-muted`) + placeholder text. Required fields marked with `*`. URL fields have SSRF hint text: "Public URLs only."
- Step 3 — Test (html_table / rss only): "Run Test" button (accent). Loading: spinner + "Fetching source…" (14px). Success: preview table (≤10 rows) showing columns: Product / Grade / Volume / Price / Currency / Section / Event At — parsed signal drafts (D-06). Failure: red error banner (see Copywriting). Cannot proceed to enable until test passes. `telegram_channel`/`llm_page` skip Test step; wizard saves to pending state directly.
- Step 4 — Enable/Save: "Enable Source" (accent, only available if test passed or type is pending) / "Save as Pending" (outline). Source cannot be set `is_enabled=true` without `last_test_ok_at IS NOT NULL` — enforced server-side.
- Wizard container: centered modal, max-width 560px, `bg-background-secondary`, `rounded-xl`, `shadow-2xl`, step indicator (numbered dots, active = accent, complete = accent check).

## Accessibility Contract

- All interactive elements: focus-visible ring `ring-2 ring-accent ring-offset-2 ring-offset-background`.
- Minimum touch target: 44px × 44px (icon-only buttons must use padding to reach this).
- Color alone never conveys status: urgency chips use icon + color. Status chips use label text + color.
- ARIA: table rows use `role="row"`, sortable column headers use `aria-sort`. Detail panel uses `role="dialog"` with `aria-labelledby` pointing to request ID heading.
- SSE connection error: non-intrusive toast (bottom-right, 4s auto-dismiss) — "Connection interrupted. Reconnecting…" — does not block interaction.
- Relative times (e.g. "2 min ago"): wrapped in `<time datetime="{ISO8601}">` for screen readers.
