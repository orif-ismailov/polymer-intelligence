| Browser session → dashboard routes | JWT presence gates route access (UX layer; API is the real boundary) |
| Login form → /auth/login | Credentials cross to backend |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-05 | Spoofing | route-group layout auth guard | mitigate | Absent/expired JWT redirects to /login; the API `require_role` deps remain the security boundary (UI guard is UX) |
| T-04-06 | Info Disclosure | api.ts token handling | mitigate | Token sent only as Authorization header to /api/v1; on 401 the client redirects (no token echo into DOM/logs) |
| T-04-07 | Tampering (XSS) | all components | mitigate | React escapes by default; no `dangerouslySetInnerHTML`; no hardcoded hex; tokens only |
