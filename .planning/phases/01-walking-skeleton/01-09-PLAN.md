<objective>
Close UAT Gap 3 / REVIEW CR-01 (major): the CI workflow and the pydantic Settings field disagree on the S3 endpoint env var name. `.github/workflows/ci.yml:79` exports `S3_ENDPOINT_URL: http://localhost:9000`, but `backend/app/core/config.py:62` declares the field as `S3_ENDPOINT: str = ""`. Because `Settings.model_config` uses `case_sensitive=True` with `extra="ignore"`, the `S3_ENDPOINT_URL` variable is silently discarded and `settings.S3_ENDPOINT` falls back to its empty-string default in CI. It is latent today (no S3 client is constructed until Phase 2/3) but it is a silent storage-misconfiguration on a required dependency that will surface as an empty endpoint URL the moment an S3/MinIO client is built from settings.

Purpose: A silent env-name mismatch on a required storage endpoint is exactly the class of bug that ships unnoticed and corrupts/loses data later. Fixing the name now and locking it with a regression test makes the mismatch loud, not silent.
Output: ci.yml exports `S3_ENDPOINT` (matching the Settings field), and a test guarantees the CI env name and the Settings field name stay in sync.

IMPORTANT — behavior-preserving constraint: the existing pytest suite is 100 passed / 17 skipped and MUST stay green. Do NOT make `S3_ENDPOINT` a required field (remove its `""` default). The test fixtures in `backend/tests/conftest.py` and `backend/tests/test_config.py` do not set `S3_ENDPOINT`; removing the default would break the entire suite. CR-01's "make it required" suggestion is therefore out of scope for Phase 1 (no S3 feature flag exists yet). The behavior-preserving fix is the CI rename plus a regression test, keeping the empty-string default intact.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator/CI config → app settings | Env vars supplied by CI/ops are read by pydantic Settings; a name mismatch silently substitutes a default, misconfiguring a dependency with no startup signal |
| app → S3/MinIO storage endpoint | `settings.S3_ENDPOINT` will later construct the storage client; an empty/wrong endpoint risks connecting to an unintended host or failing at runtime |

| T-09-02 | Repudiation (silent config drift recurs) | CI ↔ Settings env-name contract | mitigate | Regression test asserts the CI env name equals the Settings field name, converting a silent mismatch into a loud test failure |
