<objective>
Build the SourceAdapter registry — the extension point the whole product is built around (SC#4, and the no-code source constructor in Phase 4). Define the adapter Protocol (`fetch`/`test`/`config_schema`), a name-keyed registry, the shared hardened httpx fetch client (timeout/retries/UA/per-host-delay + SSRF guard against private hosts), and the `GET /admin/source-types` endpoint that exposes each adapter's config_schema so Phase-4 can auto-build the add-source form. UZEX (02-04) and CBU (02-05) adapters register against this; later phases add telegram_channel/llm_page/html_table/rss with no pipeline-code changes.

Purpose: Without the registry + contract, the concrete adapters have no interface to implement and the source-constructor (Phase 4) has no config_schema feed. The hardened HTTP client is the single chokepoint for SSRF and resource-exhaustion controls on untrusted outbound fetches.
Output: `app.ingest` package with `base.py` (Protocol + drafts), `registry.py`, `http_client.py`, and `admin_sources.py` mounting `GET /admin/source-types`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| worker → external website (outbound HTTP) | UNTRUSTED: the adapter fetches attacker-influenceable URLs/configs; SSRF + resource-exhaustion risk |
| admin client → /admin/source-types | authenticated admin reading adapter schemas; role-gated |
| source.config (jsonb) → adapter | config values (URLs, selectors) are admin-supplied and flow into fetch |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-07 | Information Disclosure / SSRF | http_client.fetch_url target host | mitigate | `is_safe_url` rejects loopback/private/link-local/reserved IPs (incl. 169.254.169.254 metadata) and non-http(s) schemes BEFORE the request; all adapters MUST route outbound fetches through fetch_url |
| T-02-08 | Denial of Service (resource exhaustion) | oversized/slow external response OOMs worker | mitigate | 30s timeout + streamed body with a hard size cap (~25 MB) + bounded retries; reject over-cap bodies without full buffering |
| T-02-09 | Tampering | unbounded retries hammering a host / being throttled | mitigate | Exponential backoff capped at INGEST_HTTP_RETRIES + ≥2s per-host delay (robots-courtesy) |
| T-02-10 | Elevation of Privilege | /admin/source-types reachable by non-admins | mitigate | `require_admin` Depends guard; test asserts 403 for trader/viewer |
| T-02-SC | Tampering | npm/pip/cargo installs | accept | No new package installs (httpx/pydantic already in pyproject). selectolax is introduced in 02-04, not here |
</threat_model>
