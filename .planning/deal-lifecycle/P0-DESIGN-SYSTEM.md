# P0 — Дизайн-система: рестайлинг портала под new-design (до всей функциональности R4)

> Prereq: `00-CONTEXT.md`. Референс: **`docs/new-design/`** (7 листов мокапов + README
> с каталогом). Решение оператора: вариант C — сначала дизайн-система, потом
> функциональность в ней. Скоуп — **только `portal/`** (dashboard — внутренний
> инструмент, не рестайлится; `webapp/` заморожен).
> **Методология:** фронтовые гейты перед каждым коммитом — `npm run lint`
> (`--max-warnings 0`) + `npm run typecheck` + Playwright e2e; визуальная сверка
> скриншотами против мокапов по чек-листу W3. Бэкенд не трогается вообще
> (полный `pytest` перед коммитом всё равно обязателен — репо-правило).

**Текущее состояние (проверено по коду):** портал токенизирован — палитра в
`portal/src/app/styles.css` (CSS custom properties, `:root`/`[data-theme="dark"]`),
`tailwind.config` читает переменные (`bg/surface/border/text/brand/success/warning/
danger/info`, radius, keyframes), тёмная тема существует (default — light), UI-кит в
`portal/src/shared/ui/` (Alert, Badge, Button, Card, Checkbox, Dialog, EmptyState,
FormField, Input, Label, LinkButton, Select, Skeleton, Spinner, StateViews, Stepper,
Textarea, Tooltip + buttonStyles). Текущий brand — синий (#2563eb/#3b82f6).

**Demo (Definition of Done):** портал по умолчанию открывается в тёмной теме в
стилистике мокапов (графитовый фон, неоново-зелёный акцент, тонкие зелёные рамки
карточек, зелёные степперы/бейджи); все существующие страницы (login/OTP, визард
компании, профиль компании, офферы, маркет, заявки, контракты, новости, уведомления,
настройки) выглядят целостно без «синих островов»; светлая тема остаётся рабочей
(вторичной) и перекрашена в тот же брендовый зелёный; мобильная нижняя навигация
как в мокапах; все e2e зелёные.

## Wave 1 — Токены и тема

### T1.1 Палитра в `src/app/styles.css`
Новые значения токенов (подобрать пипеткой по мокапам, зафиксировать в комментариях
файла; ориентиры):
- dark (становится **default**): `--bg` ~#0A0D0A–#0B0F0B (графит с лёгким зелёным
  подтоном), `--surface` ~#111511 / `--surface-2` ~#161B16, `--border` тонкий
  зелёно-серый, `--brand` неоново-зелёный ~#22C55E (кнопки мокапов ярче — до #4ADE80),
  `--brand-fg` **тёмный** (#052E10 — на мокапах текст на зелёных кнопках тёмный),
  `--warning`/золотой акцент ~#EAB308 (Laboratory Verified, премиум-бейджи),
  `--success`=brand-семейство, `--danger` красный статусов.
- light: тот же зелёный brand, нейтральные светлые поверхности (перекраска, не дизайн
  с нуля — light вторична).
- Новые токены: `--brand-glow` (тень/свечение для акцентных элементов:
  `0 0 24px color-mix(in srgb, var(--brand) 35%, transparent)`), `--accent-gold` +
  `--accent-gold-fg`. В tailwind.config добавить `boxShadow.glow` и цвет `gold`.

### T1.2 Тёмная тема — default
Переключить дефолт `data-theme` на dark (место установки — bootstrap/провайдер темы;
найти фактический код установки атрибута). Сохранение выбора пользователя (если
переключатель уже есть в настройках — оставить; если нет — добавить в Settings:
Тёмная/Светлая/Системная). Проверить `color-scheme`, скроллбары, нативные контролы.

### T1.3 Шрифт и радиусы
Мокапы — геометрический гротеск: остаёмся на Inter (уже подключён), включить
`font-feature-settings` табличных цифр для цен/статистики. Радиусы карточек по
мокапам крупнее — поднять `--radius-lg` (~16px), сверить Dialog/Card.

**Гейт W1:** lint+typecheck; smoke-скриншоты 3 страниц (login, market, company-view)
в обеих темах — контраст текста ≥ WCAG AA (проверить брендовый зелёный на тёмном
фоне и тёмный текст на зелёных кнопках).

## Wave 2 — UI-кит под мокапы

### T2.1 Проход по существующим примитивам
- `Button`: primary = зелёный с тёмным текстом + лёгкий glow на hover; secondary =
  прозрачный с тонкой рамкой; danger без изменений логики. `buttonStyles.ts` — все
  варианты через токены.
- `Badge`: варианты по мокапам — `verified` (зелёный, галочка), `lab-verified`
  (золотой), `in-stock`/`on-order`, статусные (нейтральный/жёлтый/красный/зелёный).
  Единый компонент с variant-пропом; никаких инлайн-цветов на страницах.
- `Card`: вариант `accent` — тонкая зелёная рамка (`--brand`-line) как у карточек
  модулей на мокапах.
- `Stepper`: зелёные выполненные шаги с галочками, активный — залитый зелёный круг
  (мокапы регистрации/RFQ-визарда); горизонтальный + компактный мобильный вид.
- `Alert/Skeleton/Spinner/Dialog/Input/Select/...` — сверка на токены, зачистка
  любых захардкоженных цветов (grep по `#[0-9a-fA-F]{3,8}` и `blue|indigo` в
  `src/` — вне styles.css совпадений быть не должно).

### T2.2 Новые примитивы (нужны мокапам и планам P1–P6 — только каркас, без бизнес-логики)
- `BottomNav` — мобильная нижняя навигация (Главная/Заявки/Маркет/Сделки/Профиль;
  пункт «Сделки» появится в P2 — сейчас роуты существующие), скрывается на desktop
  (там остаётся текущая навигация).
- `StatusStepper` — вертикальный таймлайн статусов с галочками (мокапы сделки/
  D-Doc/Escrow) — понадобится P2/P3; здесь — компонент + стори-страница.
- `StatChip` — мини-карточка метрики (число + подпись, как «50 000+ / 120+ / 98%»).
- `ProgressRing` — круговой прогресс (экран AI-проверки) — используется позже.
Каждый — в `shared/ui`, экспорт в `index.ts`, минимальный vitest/tsx-рендер тест
(если в портале нет vitest — покрыть e2e-стори-страницей `/dev/ui` за DEV-флагом).

**Гейт W2:** lint+typecheck; grep-чистота hex; e2e не сломаны.

### Решения, которые стоит помнить

- **`tailwind.config.ts` не трогали.** Именованная утилита (`text-h1`) переименовывает
  решение на месте вызова, а не убирает его; при этом **ни один из закреплённых тестов
  не видит размер шрифта** — все 18 меряют цвет, контраст, ARIA, `data-*` или литералы.
  Неверная шкала прошла бы полностью зелёный прогон. Шкала живёт в примитивах и в
  `docs/design-system.md` §P6.
- **`Tabs` — не `role="tablist"`.** Эти переключатели фильтруют список, который живёт вне
  их; tablist без `tabpanel` — нарушение axe там, где обычная toggle-кнопка им не является.
- **`StepConfirm` оставлен со своим `<dl>`** — это третья форма (значение по правому краю),
  ровно одно место, вариант не оправдан.

### Что нашлось глазами, а не тестами

- Полоса вкладок внутри колонки грида **молча расширяла страницу до 401px при вьюпорте
  375px** вместо прокрутки: автоминимум grid-элемента — это min-content его содержимого,
  и `overflow-x-auto` эту цепочку не разрывает. Ширину страницы не меряет ничто в сьюте.
- `aria-label` гамбургера в топбаре был `nav.home` — единственный элемент навигации на
  телефоне представлялся «Главной».
- Падение `r3-contracts` было **не наше**: в QA-базе не выставлен app-setting
  `verification_auto_approve`, вторая компания не верифицировалась и форма договора
  корректно её отклоняла. Воспроизводится на нетронутом baseline.
