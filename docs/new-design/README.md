# IMEX AI — новый дизайн (мокапы из продуктового обсуждения, 27.07.2026)

Референсные мокапы целевого продукта. Функциональное покрытие — трек
`.planning/deal-lifecycle/` (TZ.md + P-планы). Этот файл привязывает каждый лист
к планам и фиксирует расхождения, найденные при сверке.

## Дизайн-система (общая для всех листов)

- Тёмная тема (чёрный/графит #0A0A0A–#111), акцент — неоновый зелёный (~#22C55E–#7CFF3A),
  предупреждения/премиум — жёлтый/золотой, статусы — зелёный/жёлтый/красный.
- Карточки со скруглениями и тонкими зелёными рамками; бейджи-чипы (Verified,
  Laboratory Verified, В наличии/Под заказ); степперы прогресса с зелёными шагами.
- Мобильная нижняя навигация: Главная · Заявки · Маркет · Сделки/Сообщения · Новости · Профиль.

## Расхождения, внесённые в ТЗ при сверке (27.07.2026)

1. **RFQ-визард**: требуемые документы от поставщика (чек-лист SDS/COA/происхождение/КП),
   видимость заявки (только verified по умолчанию / все / выбранные), канал получения
   предложений → ТЗ FR-D10, реализация в P2.
2. **Готовность к сделке** на оффере (принимаю RFQ / готов подписывать через ЭДО /
   принимаю Escrow) → ТЗ блок E, P4 Wave 1.
3. **Избранное** (сердечко на карточках) → ТЗ блок E (малое).
4. **AI Market Insight** на карточке товара (рыночный диапазон из наших price-данных,
   «цена выгодна на N%») → кандидат R5+, за настройкой; источники цен в платформе уже есть.

## Что в мокапах сознательно НЕ в скоупе трека (ТЗ §3.7)

AI Trust Score, отзывы/рейтинги компаний, показатели «98% доставок в срок» (данные
появятся после накопления завершённых сделок), санкционные списки/бенефициары,
Trade Finance сверх Escrow, Email-канал уведомлений.
