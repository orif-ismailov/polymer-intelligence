## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Web App → GET /webapp/requests[/{id}] | The list/detail read only the caller's own data; backend IDOR-scoping (03-02) is authoritative; the frontend must not request by arbitrary id without auth |
| Web App → PATCH /webapp/me | Language change writes to the caller's own client row only (scoped by initData server-side) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-18 | Information disclosure | detail view rendering another client's request | mitigate | RequestDetail fetches via api.getRequest(id) which is initData-scoped server-side (03-02 T-03-07); a non-owned id returns 404 and the UI shows the load error (Task 1) |
| T-03-19 | Tampering | language PATCH affecting another client | mitigate | PATCH /webapp/me is scoped to the verified client (03-02); the frontend sends no client id (Task 2) |
| T-03-20 | Denial of service | oversized bundle blocking 3G first paint | mitigate | Route-level code-split + manualChunks + named lucide imports; build-time gzip gate ≤300 KB (Task 2) |
</threat_model>
