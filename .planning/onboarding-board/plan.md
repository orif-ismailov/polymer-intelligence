## 3. Шесть правил прохождения

Выросли из собственных ошибок в этой сессии, а не из общих соображений.

1. **Только живой продукт.** Ни один кадр и ни одна находка не берутся из кода или памяти.
   Подтверждение — запись сети и строка в Postgres.
2. **Метка привязана к настоящему элементу.** `annotate.js` берёт `getBoundingClientRect()`
   и требует `expect` — ожидаемую подстроку в тексте элемента. Не совпало → метка **не
   рисуется**, возвращается ошибка. Плюс отказ, если элемент занимает больше половины
   документа (эвристика любит ловить обёртку вместо кнопки).
3. **Прогрев перед снимком.** `settle()` прокручивает страницу целиком. Без этого ленивые
   секции и анимированные счётчики попадают в кадр недорисованными.
4. **Врезка с фактами.** Реальный ответ сервера и изменение в базе, а не пересказ.
5. **Смотреть на кадр глазами.** Снял → открыл → посмотрел.
6. **Не досочинять.** Не воспроизвелось → в раздел «Не исследовано», а не в описание.

### Цена нарушения правил 2, 3 и 5 — реальный случай

Находка **F-08** сначала была записана неверно: «блок ПЛАТФОРМА В ЦИФРАХ показывает нули».
Я взял это из дерева доступности, где стояли `0 / 0 / 0,0`. На прогретой странице выяснилось,
что счётчики **анимированы** и набегают от нуля, а показывают `1 500+ / 10 000+ / 99,8 %`.
Находку переписал: числа зашиты в вёрстку и с базой не связаны — платформа с нулём сделок
публично заявляет о 10 000 успешных. Отзыв прежней формулировки зафиксирован в `findings.md`.

Тогда же метка отказалась ставиться на элемент с ожидаемым текстом — и это был **правильный**
отказ: `innerText` возвращает текст после CSS `text-transform`, `textContent` — сырой,
поэтому «ПЛАТФОРМА В ЦИФРАХ» не находилась по `textContent`. Искать по `innerText`.

## 4. Стенд

База обнулена: `DROP SCHEMA public CASCADE` → `alembic upgrade head` (голова **0047**) →
5 сидеров (`seed_reference`, `seed_staff`, `seed_sources`, `seed_substances`,
`seed_contract_templates`). Redis `FLUSHALL`, бакет MinIO очищен.

**`app_settings` сохраняются и восстанавливаются** — иначе Fernet-шифрованный токен Didox
теряется безвозвратно, прочитать его в открытом виде нельзя:

```bash
docker exec pi-pg pg_dump -U pi -d polymer --data-only --table=app_settings \
  --column-inserts > /tmp/app_settings_backup.sql
# … снос, миграции, сидеры …
docker cp /tmp/app_settings_backup.sql pi-pg:/tmp/s.sql
docker exec pi-pg psql -U pi -d polymer -f /tmp/s.sql
```

|---|---|---|

**Аннотатор.** Раздаётся локально, вставляется тегом в любую страницу:

```bash
node /tmp/ann-server.mjs   # отдаёт annotate.js на :8788 с CORS
```

```js
// в evaluate_script
await new Promise((res,rej)=>{const s=document.createElement('script');
  s.src='http://127.0.0.1:8788/annotate.js';s.onload=res;s.onerror=rej;document.head.appendChild(s)});
const a = window.__ann; a.reset(); await a.settle();
a.caption('07 · Заголовок кадра', 'подзаголовок');
a.mark(el, 1, 'подпись', { expect: 'текст элемента' });
a.inset('ЧТО НА СЕРВЕРЕ', ['POST … → 204', 'user_accounts: 0 → 1']);
```

Кадры: `.tmp-onboarding/shots/` (вне git).

**Две раскладки кадра, выбирать по экрану:**

- **Просторный экран** (мастер регистрации, витрина — контент узкой колонкой по центру):
  подпись прямо у метки, `side` по умолчанию. Так сняты кадры 01–16.
- **Плотный экран кабинета** (боковое меню + широкая карточка): на кадре **только номера**,
  весь текст — одной врезкой «ЧТО ОТМЕЧЕНО НА КАДРЕ» под контентом. Иначе плашки либо
  садятся на меню, либо раздувают холст: абсолютно позиционированный блок за пределами
  контента увеличивает `scrollHeight`/`scrollWidth`, и полностраничный снимок обрастает
  пустотой. Так снят кадр 18.

**Что аннотатор теперь отказывается делать** (каждый запрет вырос из испорченного кадра):

- метка на элементе внутри `sticky`/`fixed` предка — координаты уедут при прокрутке
  (боковое меню кабинета `fixed`, шапка `sticky`). Снимается `stickyOk: true`, но только
  при `scrollY === 0`;
- метка на элементе, занимающем больше половины документа, — это обёртка, а не контрол;
- метка, если текст элемента не содержит `expect`.

Полезное: `side: 'left'|'right'` — сторона подписи, `at: {x, y, width}` — подпись в явном
месте, `caption(…, {x, y, width})`, `inset(…, {x, y, width})`.
