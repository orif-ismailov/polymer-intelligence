## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Admin → POST/PATCH /alert-rules | Rule condition JSONB + chat_ids cross to storage |
| alert_service → Telegram bot | Alert bodies dispatched to external chat_ids |
| Browser → /prices/series, /alerts | Reads cross to backend |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-24 | Tampering (code exec) | alert condition JSONB | mitigate | Hardcoded per-key interpreter, NEVER eval; condition values bound as ORM/SQL params, never interpolated (grep eval == 0) |
| T-04-25 | Elevation | POST/PATCH /alert-rules | mitigate | require_admin on rule writes; non-admin -> 403 |
| T-04-26 | Denial of Service | alert storm (large batch) | mitigate | Deliveries go through the single notify queue + token-bucket (25 msg/s bot, 1 msg/s chat_id); dedupe_key collapses duplicate rule+entity alerts (Pitfall 7) |
| T-04-27 | Tampering (SQLi) | /prices/series filter params | mitigate | sa.text bound params for product_id/market/date range; no string interpolation |
| T-04-28 | Repudiation | rule create/edit | accept | created_by recorded; alert-rule edits are admin-only and low-frequency; full audit of rule edits not required for Phase-1 acceptance |
| T-04-SC | Tampering | pip installs | accept | No package installs in this plan |
</threat_model>
