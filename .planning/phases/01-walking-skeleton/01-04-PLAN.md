<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| internet → nginx | All external traffic terminates TLS at nginx; first untrusted hop |
| nginx → api/dashboard | Reverse proxy to internal services; only intended paths exposed |
| CI runner → container registry | Built images must come from reviewed source; supply-chain surface |
| repo → frontend bundle | Frontend must not embed secrets or hardcoded credentials |
| internet → /api/v1/auth/login | High-value unauthenticated endpoint; brute-force / credential-stuffing surface throttled at nginx |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering | in-transit traffic | mitigate | nginx is TLS-ready (certbot cert paths, HTTP→HTTPS redirect, HSTS header) per REQ-nfr-security HTTPS-everywhere |
| T-04-02 | Information Disclosure | secrets in frontend bundle | mitigate | Frontends are shells with no secrets; only public config; acceptance forbids hardcoded colors/secrets in dashboard components |
| T-04-03 | Tampering | clickjacking / MIME sniffing | mitigate | nginx sets X-Frame-Options/frame-ancestors and X-Content-Type-Options nosniff |
| T-04-04 | Spoofing / Tampering | CI dependency supply chain | mitigate | CI pins action versions and language versions; deps resolve from the locked pyproject/package.json; image build gated behind passing lint+tests |
| T-04-05 | Information Disclosure | over-broad proxy exposure | mitigate | nginx proxies only `/api/` to the api service; internal services (postgres, redis) are not exposed through nginx |
| T-04-06 | Spoofing / Denial of Service | credential stuffing / brute-force on `/api/v1/auth/login` (ASVS L1 V2.2.1) | mitigate | nginx `limit_req_zone` keyed on `$binary_remote_addr` (rate ≈10r/m, burst 5) on a dedicated `location = /api/v1/auth/login`, returning HTTP 429 over the limit; closes the gap for plan 01-03's login endpoint (cross-ref T-03-09). Verified by `nginx -t` + grep acceptance |
| T-04-SC | Tampering | npm/pip installs in CI | mitigate | Backend deps are the canonical locked stack; frontend deps are the dev-spec §6 locked libraries — all well-known registry packages; no [ASSUMED]/[SUS] packages introduced |
