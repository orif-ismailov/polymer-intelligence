## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-15 | Tampering (XSS) | request fields, notes rendered | mitigate | React text rendering (escaped); no dangerouslySetInnerHTML; notes shown as text |
| T-04-16 | Elevation | action buttons for viewer | mitigate | UI hides/disables write actions for viewer (UX); server require_role is the real gate (04-04) |
| T-04-17 | Error/Crash | Contact Buyer NULL telegram_user_id | mitigate | Button disabled + tooltip when contact_available=false; no tg://user?id=None opened (Pitfall 6) |
| T-04-18 | DoS | CSV export large result | mitigate | Backend caps export at 50,000 rows; StreamingResponse avoids loading all rows in memory |
| T-04-SC | Tampering | npm installs | accept | No new packages (uses shadcn components from 04-02) |
</threat_model>
