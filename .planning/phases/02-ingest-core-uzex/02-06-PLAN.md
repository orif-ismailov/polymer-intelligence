<objective>
Make ingest health observable and self-alerting with failure isolation. Wrap each per-source fetch so a success resets the failure counter and a failure increments it; when any one source hits 3 consecutive failures, raise a `source_failure` alert (deduped per source per day) that surfaces within 30 minutes via the `*/5` check_source_health beat task — while sibling collectors keep running unaffected. Expose `GET /admin/sources/health` for the dashboard Sources screen.

Purpose: REQ-sources-health + the reliability half of REQ-nfr-reliability + SC#5 ("one source fails 3 cycles → alert ≤30 min, others keep running, success resets the counter"). This is the safety net that makes the multi-source pipeline trustworthy.
Output: `source_health_service` (success/failure recording + 3-strike deduped alert), failure-isolation wrapping in the fetch tasks, the `check_source_health` beat task, and the sources-health API.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| collector exception → health state | failure data drives alerting; mis-recording could mask outages |
| admin client → /admin/sources/health | role-gated read of operational state |
| alert dedupe_key → alerts table | concurrent failures could race to create duplicate alerts |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-19 | Denial of Service | one failing source aborting the whole beat batch (cascading outage) | mitigate | run_source_fetch_isolated try/except per source — a failure is recorded and the loop continues; no exception escapes the per-source unit (SC#5) |
| T-02-20 | Repudiation / alert storm | duplicate source_failure alerts flooding the channel | mitigate | dedupe_key source_failure:{source_id}:{date} + UNIQUE(dedupe_key) ON CONFLICT DO NOTHING → at most one alert per source per day |
| T-02-21 | Information Disclosure | health endpoint leaking source secrets (config/credentials) | mitigate | /admin/sources/health returns ONLY health + identity fields, never sources.config or credentials; require_admin guard |
| T-02-22 | Tampering | the */5 scan masking a real failure if inline path missed | mitigate | check_all_sources_health independently re-scans and (idempotently) raises for any ≥3-failing source — defense in depth on the ≤30 min guarantee |
| T-02-SC | Tampering | npm/pip/cargo installs | accept | No new package installs in this plan |
</threat_model>
